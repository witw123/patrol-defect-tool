# 巡检缺陷命名分类工具 (Patrol Defect Tool)

> 电力架空线路 / 配电网无人机巡检缺陷标记、双目录规范化命名与分类归档工具。纯前端自包含架构，单 HTML 文件双击即用，支持离线运行与本地安全文件系统访问（File System Access API）。

---

## 核心特性

### 1. 智能目录树与手风琴排他自动收起
- **看到当前塔基自动展开**：浏览切换照片时，左侧目录树自动展开该塔基及所属线路，并平滑居中滚动至视口正中。
- **看过后自动收起（手风琴排他联动）**：当焦点离开当前塔基（切换至新塔基或跨线路）时，系统自动将所有非当前塔基折叠收起，始终只展开当前正在查勘的一基杆塔，保持数百上千张长列表界面清爽聚焦。
- **带相对路径的防串号已看统计**：按 `线路/杆塔/照片` 的相对路径建立唯一索引，彻底消除跨塔同名照片引起的统计串号，并自带旧版数据自动清洗机制。
- **直达最后一个已看照片**：快捷键 `C` 或悬浮定位按钮一键直达，配合居中平滑定位与柔和呼吸灯高亮。

### 2. 缺陷自动归类与「全绝缘」/「其它缺陷」一键分类
- **右上角操作区一键分类**：顶栏右上角设置「⚡ 一键分类全绝缘与其它缺陷」按钮，一键扫描当前输出成果，自动创建「全绝缘缺陷」与「其它缺陷」独立文件夹并归类圈示图与原图。
- **自定义全绝缘关键词**：
  - 在「设置」面板中可自定义全绝缘缺陷关键词（多个关键词以逗号或空格分隔，默认：`绝缘, 裸导线`）。
  - 支持一键「恢复默认」关键词。
  - 导出/导入分类模板时自动打包与同步全绝缘关键词配置。
- **保存时自动同步分流（默认关闭，按需开启）**：
  - 可在「设置」中随时开启/关闭「自动分类全绝缘/其它缺陷」（默认关闭，保持单目录输出简洁）。
  - 开启后，保存缺陷时自动判断是否命中关键词，同步归档至 `全绝缘缺陷/` 或 `其它缺陷/` 子目录。
- **无损归档与安全防护**：一键分类以非破坏性拷贝方式归档，原始「缺陷圈示图」与「缺陷原图」目录完整保留无损。

### 3. 操作效率与快捷键系统
- **键盘快捷键自定义**：支持自定义绑定上一张、下一张、保存缺陷按键（默认 `A` / `D` / `F`，方向键与空格同样可用）。
- **鼠标侧键与手势翻图**：支持罗技等鼠标的前进/后退侧键翻图；可选开启图片区域左键单击下一张、右键单击上一张（拖拽仍保持圈框与平移）。
- **防黑屏无损还原**：取消标记或删除已标缺陷时，精准还原并重载纯净原始大图，杜绝黑屏卡死。
- **极速丝滑切图**：显存纹理复用 + 后台并发预解码，大图秒出零卡顿。

### 4. 检查结论与画质检测
- **检查结论核定**：支持设置 `待检查` / `确认无缺陷` / `发现缺陷` / `需复核` / `图片不可用` 并实时汇总进度。
- **图片质量与分辨率指示**：工具栏实时展示原图真实分辨率（如 `3840×2160 · 4K 原图`）。

## 快速使用

1. 使用 Chromium 内核现代浏览器（Google Chrome、Microsoft Edge 等）直接双击打开 `巡检缺陷命名分类工具.html`。
2. 点击顶栏 **「选择照片文件夹」** 载入巡检照片目录。
3. 点击 **「设置保存输出文件夹」** 连接缺陷输出目录。
4. 按 `A` / `D` 键或鼠标快速翻阅照片；在图上拖动鼠标圈出缺陷部位，并在右侧选择对应部件与缺陷标签，按 `F` 键或空格即刻同步保存！
