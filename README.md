# 巡检缺陷命名分类工具 (Patrol Defect Tool)

> 电力架空线路 / 配电网无人机巡检缺陷标记、双目录规范化命名与分类归档桌面工具。基于 **Tauri 2.0 (Rust) + 高性能前端** 架构，提供原生级文件读写速度、毫秒级切图响应与便携本地持久化。

---

## 核心特性

### 1. 毫秒级极速切图与智能已看追踪
- **大图毫秒级切换**：自研 `pdefile://` 自定义协议与高性能并行解码，快速切图零阻塞。
- **O(1) 实时已看状态直查**：毫秒级直查与状态统计，彻底解决万张照片下的防串号与状态丢失问题。
- **智能目录树与手风琴排他自动收起**：浏览切换照片时，左侧目录树自动展开当前塔基及所属线路并平滑居中滚动；离开时自动折叠非当前塔基，聚焦当前查勘目标。
- **直达最后一个已看照片**：快捷键 `C` 或悬浮定位按钮一键直达，配合居中平滑定位与柔和呼吸灯高亮。

### 2. 缺陷「全绝缘」/「其它缺陷」一键分类与规范化输出
- **右上角操作区一键分类**：顶栏右上角设置「⚡ 一键分类全绝缘与其它缺陷」按钮。
- **智能识别与非破坏性归档**：
  - 自动扫描当前输出目录中的缺陷成果照片。
  - 缺陷标签或文件名带有「绝缘」或「裸导线」的，归类整理至 `全绝缘缺陷/`（含圈示图与原图子目录）。
  - 其余缺陷自动归类整理至 `其它缺陷/`（含圈示图与原图子目录）。
  - 原始「缺陷圈示图」与「缺陷原图」目录完整保留无损。

### 3. 操作效率与快捷键系统
- **键盘快捷键自定义**：支持自定义绑定上一张、下一张、保存缺陷按键（默认 `A` / `D` / `F`，方向键与空格同样可用）。
- **鼠标侧键与手势翻图**：支持罗技等鼠标的前进/后退侧键翻图；可选开启图片区域左键单击下一张、右键单击上一张。
- **防黑屏无损还原**：取消标记或删除已标缺陷时，精准还原并重载纯净原始大图，杜绝黑屏卡死。

### 4. 可靠的便携持久化（零残留安全写入）
- **便携模式优先**：程序同级目录存在 `data/` 文件夹时（如 U 盘/移动硬盘版），自动启用便携存储模式；否则保存在 `%LOCALAPPDATA%\PatrolDefect\data`。
- **防锁死原子覆写**：针对 Windows 杀毒软件与文件系统锁，采用确定性单一临时文件与轻量重试机制，杜绝临时文件无限泄漏。
- **数据白名单清洗**：自动过滤无关大键与异常数据，保证存储文件紧凑轻量。

## 开发与构建指南

### 环境要求
- [Node.js](https://nodejs.org/) (>= 18)
- [Rust](https://www.rust-lang.org/) (>= 1.75)
- Windows 10/11 (WebView2 运行时通常已内置)

### 项目结构
```text
tauri-app/
├── src-tauri/          # Rust 后端（Tauri 2.0、自定义流式协议、确定性安全原子写）
│   ├── src/main.rs     # 后端核心逻辑
│   ├── Cargo.toml      # Rust 依赖配置
│   └── tauri.conf.json # Tauri 窗口与打包配置
└── ui/                 # 前端界面与业务逻辑
    ├── tauri-shim.js   # 浏览器 File System Access API 原生桥接层
    ├── index.html      # 主界面
    ├── js/             # 缺陷处理、目录树、快捷键、切图与导出模块
    └── css/            # 界面样式
```

### 开发调试
```bash
cd tauri-app
npm install
npm run dev
```

### 生产打包
```bash
cd tauri-app
npm run build
```
打包生成的可执行文件与安装程序位于：
- 便携免安装版：`tauri-app/src-tauri/target/release/PatrolDefect.exe`
- NSIS 安装包：`tauri-app/src-tauri/target/release/bundle/nsis/巡检缺陷命名分类工具_<版本>_x64-setup.exe`
