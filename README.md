# 巡检缺陷命名分类工具 (Patrol Defect Tool)

电力架空线路与配电网巡检照片缺陷标注、规范化命名与分类归档工具。

## 项目结构

- **`tauri-app/`**：基于 Tauri 2.0 (Rust) 的桌面客户端版本。

## 构建与运行

```bash
cd tauri-app

# 安装依赖
npm install

# 本地调试
npm run dev

# 打包发布
npm run build
```

打包产物位于 `tauri-app/src-tauri/target/release/`。
