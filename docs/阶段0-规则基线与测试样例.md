# 阶段 0：规则基线与测试样例

## 目的

先冻结旧 HTML 的行为，避免原生重写后文件名、分类或统计发生隐性变化。

## 实现任务

1. 从 HTML 提取默认分类、缺陷标签、危急缺陷和推荐关系。
2. 提取线路、杆塔、照片路径解析规则。
3. 提取缺陷文件名生成和清理规则。
4. 准备包含中文、数字后缀、重复文件名和多级目录的样例。
5. 为每条规则建立输入与期望输出。

## 产出

- `Domain` 默认规则数据。
- 命名规则单元测试。
- 分类规则单元测试。
- 路径解析单元测试。
- 一份 HTML 输出快照。

## 完成标准

规则测试全部通过；同一输入在旧 HTML 和规则测试中得到相同线路、杆塔、分类和文件名。
