# 阶段 6：发布与最终验收

## 实现任务

1. 完成单元测试和集成测试。
2. 用真实巡检目录与 HTML 结果进行对比。
3. 验证高 DPI、窗口缩放和深色模式。
4. 验证坏图、权限不足、重复文件和超长路径。
5. 添加崩溃日志和操作日志。
6. 配置 GitHub Actions Windows 构建。
7. 生成 x64 self-contained 发布包。
8. 生成 MSIX 安装包。
9. 验证安装、启动、卸载和升级。

## 最终验收

- `01-功能分类规格.md` 中所有项目通过。
- 输出目录、文件名、图片尺寸和标注位置与 HTML 对照一致。
- 无 HTML、浏览器、Electron 或 WebView 运行依赖。
- GitHub Actions 可重复生成可下载产物。
- 完成一次真实项目全流程使用。

只有以上条件全部满足，才称为“完整替代原 HTML 工具”。
