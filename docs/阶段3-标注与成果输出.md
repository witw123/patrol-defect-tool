# 阶段 3：标注与成果输出

## 目的

完成核心业务闭环：浏览照片、框选缺陷、分类、保存并恢复成果。

## 实现任务

1. 绘制、选中、移动、调整和删除多个矩形。
2. 实现撤回和清空二次编辑。
3. 实现 2 至 30px 线宽。
4. 实现部件、缺陷标签和结论选择。
5. 实现文件名预览和标签撤回。
6. 生成圈示图并复制纯净原图。
7. 按规则输出全绝缘缺陷和其他缺陷。
8. 独立保存和撤回危急缺陷。
9. 取消标记时清理所有关联成果。
10. 保存数据库记录并支持重启恢复。

## 完成标准

输入原图不被修改；输出目录结构和文件命名与 HTML 一致；关闭重启后标注、结论和已标记状态一致。

## HTML 源码补充约束

依据 `saveBothFolders` 和 `newNamePreview`：

- 未画框或未选标签时原版允许确认后保存，不是无条件禁用。
- 普通保存替换当前照片原有成果；二次编辑才保留原成果并生成独立成果。
- 主保存遇到危急标签还会生成危急图；危急独立按钮是另一条操作流程。
- 裸导线保存前需确认命名区段，区段通过 `getCustomBaseName` 替换名称。
- 已圈示图上继续画框时，以已有圈示底图叠加，而原图成果始终来自纯净输入。

上述是待实现/验收约束，不代表当前窗口已实现。区段纯规则测试通过不能替代原生弹窗和实际成果测试。
