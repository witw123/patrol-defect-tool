# 阶段 2：原生窗口与图片画布

## 目的

用 WinUI 3 完成与原 HTML 相同的三栏工作区和图片操作。

## 实现任务

1. 建立顶部工具栏、左目录区、中间画布、右信息区。
2. 接入原生目录选择器。
3. 显示线路、杆塔和照片树。
4. 异步加载和解码图片。
5. 实现适应窗口、缩放、平移。
6. 实现原图和圈示图切换。
7. 实现图片缓存和前后预加载。
8. 显示照片计数、文件名和真实分辨率。
9. 实现左右栏拖动调整宽度。

## 产出

- 原生主窗口。
- `ImageViewport`。
- `ImageCache`。
- `ImageDecoder`。

## 完成标准

加载上千张照片时 UI 仍可操作；窗口缩放不改变图片比例；切图不会黑屏；原图与圈示图可正确切换。
