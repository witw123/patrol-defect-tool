# 总览与边界

## 目标

将现有单文件 HTML 工具完整重写为 Windows 原生桌面软件。

## 技术边界

- C#、.NET 8、WinUI 3。
- SQLite 保存项目状态、标注、规则和输出映射。
- Windows 原生文件系统处理目录和文件。
- Windows Imaging Component / Win2D 处理图片。
- ClosedXML 读取现有 Excel 词典。
- 不嵌入 HTML，不使用浏览器运行时。

## 软件分层

```text
PatrolDefect.App             窗口、页面、控件、快捷键
PatrolDefect.Application     用例、命令、进度、校验
PatrolDefect.Domain          照片、标注、分类、命名规则
PatrolDefect.Infrastructure  SQLite、文件系统、Excel、日志
PatrolDefect.Imaging         解码、缓存、画布、成果图
```

## 全局原则

- 相对路径是照片唯一业务键。
- 输入原图永不修改。
- 输出写入采用临时文件后替换。
- UI 线程不执行递归扫描、图片解码和批量复制。
- 先完成可验证闭环，再增加后续功能。
- 不添加旧版兼容层或迁移 fallback。
